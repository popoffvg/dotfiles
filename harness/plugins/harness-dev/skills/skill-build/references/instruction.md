# Skill shape: instruction (rules & reference)

A **flat set of rules, definitions, or facts** consulted on demand — a checklist, a style guide, a glossary. Order does not matter, so a flat peer-set is the correct arrangement.

Each rule stands alone under its own heading or bullet; a concept's definition, rules, and caveats sit together (`text-style` → Co-locate). Phrase each rule as the positive target. Bind the set to an exhaustive gate — "every rule applied" — so flat reference drives the same legwork ordered steps do.

Output: `SKILL.md` with frontmatter plus the rule set.
