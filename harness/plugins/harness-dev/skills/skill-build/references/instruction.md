# Skill shape: instruction (rules & reference)

Author a skill whose body is a **flat set of rules, definitions, or facts** the agent consults on demand — a review checklist, a style guide, a glossary. No ordered steps: order does not matter here, so a flat peer-set is the correct arrangement, not a smell. Shared vocabulary: `foundations.md`.

## Structure

Each rule stands alone under its own heading or bullet, every rule on one rung. Co-locate a concept's definition, rules, and caveats under one heading, so reading one part brings its neighbours.

## Make each rule bind

Tie the set to an **exhaustive** gate — "every rule applied" — so flat reference drives the same legwork ordered steps do (`foundations.md` → Completion criteria). Phrase each rule as the positive target behaviour.

## Output

`SKILL.md` with frontmatter plus the flat rule-set, co-located by concept, each rule positive and load-bearing.
