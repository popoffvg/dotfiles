# Skill shape: workflow (ordered steps)

An **ordered sequence of steps** run once, top to bottom. Each step is one imperative action, verb-first. Number the steps only when the order is load-bearing.

Each step ends on its **completion criterion** (`text-style`), written into the step itself: "every modified model appears in the change list", not "review the models".

Output: `SKILL.md` with frontmatter plus the steps; detailed lookups disclosed to `references/`.
