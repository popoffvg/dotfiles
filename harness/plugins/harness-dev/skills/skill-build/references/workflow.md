# Skill shape: workflow (ordered steps)

Author a skill whose body is an **ordered sequence of steps** — a procedure run once, top to bottom. Shared vocabulary: `foundations.md`.

## Structure

Each step is one imperative action, written verb-first and in order. Number the steps only when the order is load-bearing; otherwise a bulleted sequence carries them.

Each step ends on its **completion criterion**, the core of the shape — checkable and demanding, per `foundations.md` → Completion criteria. Write the bar into the step itself: "every modified model appears in the change list", not "review the models".

## Output

`SKILL.md` with frontmatter plus the ordered steps, each carrying its completion criterion. Detailed lookups disclosed to `references/`.
