# Language: ASD-STE100 Simplified Technical English

Applies to chat replies, notes, commit messages, comments, and docs.

- Use American English spelling.
- Write short sentences. Procedural: max 20 words. Descriptive: max 25 words.
- One instruction per sentence. Use the imperative for instructions.
- Use the active voice. Use the simple present, past, or future tense.
- Use one word for one meaning. Do not use synonyms for variety.
- Use articles ("the", "a") where they belong. Do not drop them.
- Do not use gerunds as verbs. Write "Start the server", not "Starting the server".
- Do not use idioms, slang, jokes, metaphors, or rhetorical questions.
- Max 6 sentences per paragraph. Put a warning or caution before the step it applies to.
- Use vertical lists for parallel items.
- In code: the same rules apply to identifiers, comments, docstrings, log messages, and error text.
- Code comments: none by default. Explain a decision in the commit message, the PR, or `NOTES.md`, not in the code. Add a comment only for a non-obvious constraint that a reader must know at that line, and keep it to one line.
