# HTTP server

One shape for every Go HTTP server: the standard `net/http` `ServeMux` and plain `http.HandlerFunc` handlers, one route table, an OpenAPI spec generated from that table by [`swaggest/openapi-go`](https://github.com/swaggest/openapi-go), a slog logger middleware outside, and an auth middleware that the table applies.

## Why openapi-go

The OpenAPI spec MUST come from the Go types the handlers decode and encode. A spec written by hand, or in comments, drifts from the code.

| Library | Spec source | Verdict |
| --- | --- | --- |
| `swaggest/openapi-go` (`openapi3` or `openapi31`) | Go request and response structs, reflected | Use it. A library, not a framework: handlers stay `http.HandlerFunc`, the mux stays `ServeMux`. |
| `danielgtaylor/huma/v2` | Go structs | Reject. Replaces the handler signature with its own. |
| `swaggo/swag` | Comments above handlers | Reject. Comments drift; the stable line emits Swagger 2.0 only. |
| `oapi-codegen`, `ogen` | A YAML spec, Go generated from it | Use only when the spec is the contract and another team owns it. |

## Route table

Every route is one row. The reader registers the row on the mux, wraps it in auth, and adds it to the spec. No route reaches the mux any other way, so the spec, the mux, and the auth check cannot disagree.

```go
type route struct {
	method   string
	path     string
	id       string            // OpenAPI operationId
	handler  http.HandlerFunc
	request  any               // nil: no body or parameters
	response map[int]any       // status → body type; problemBody for errors
	public   bool              // true: no bearer token needed
}

func (s *Server) routes() []route {
	return []route{
		{method: http.MethodGet, path: "/healthz", id: "getHealth",
			handler: s.healthz, response: map[int]any{http.StatusNoContent: nil}, public: true},
		{method: http.MethodPost, path: "/api/v1/users", id: "createUser",
			handler: s.createUser, request: new(createUserRequest),
			response: map[int]any{
				http.StatusCreated:  new(createdUser),
				http.StatusConflict: new(problemBody),
			}},
	}
}
```

`public` is the per-row exception. The reader MUST NOT branch on a path or an id.

## Wiring

```go
const bearerScheme = "bearerAuth"

func NewServer(addr string, log *slog.Logger, tokens TokenVerifier, users *user.Users) (*http.Server, error) {
	s := &Server{users: users}
	mux := http.NewServeMux()
	spec := openapi3.NewReflector()
	spec.Spec.Info.WithTitle("miniauth").WithVersion("1.0.0")
	spec.Spec.SetHTTPBearerTokenSecurity(bearerScheme, "opaque", "Admin token")

	for _, r := range s.routes() {
		h := http.Handler(r.handler)
		if !r.public {
			h = requireAuth(tokens, h)
		}
		mux.Handle(r.method+" "+r.path, h)
		if err := addOperation(spec, r); err != nil {
			return nil, fmt.Errorf("httpapi: spec %s %s: %w", r.method, r.path, err)
		}
	}
	doc, err := spec.Spec.MarshalYAML()
	if err != nil {
		return nil, fmt.Errorf("httpapi: marshal spec: %w", err)
	}
	mux.HandleFunc("GET /openapi.yaml", func(w http.ResponseWriter, _ *http.Request) {
		w.Header().Set("Content-Type", "application/yaml")
		_, _ = w.Write(doc)
	})

	return &http.Server{
		Addr:              addr,
		Handler:           logRequests(log, mux),
		ReadHeaderTimeout: 5 * time.Second,
		ErrorLog:          slog.NewLogLogger(log.Handler(), slog.LevelError),
	}, nil
}

func addOperation(spec *openapi3.Reflector, r route) error {
	op, err := spec.NewOperationContext(r.method, r.path)
	if err != nil {
		return err
	}
	op.SetID(r.id)
	if !r.public {
		op.AddSecurity(bearerScheme)
	}
	if r.request != nil {
		op.AddReqStructure(r.request)
	}
	for status, body := range r.response {
		op.AddRespStructure(body, func(cu *openapi.ContentUnit) { cu.HTTPStatus = status })
	}
	return spec.AddOperation(op)
}
```

- Auth MUST fail closed: a row is wrapped unless it says `public: true`. Forgetting the field gives a secured route, never an open one.
- The spec MUST be served from the generated bytes. If a committed `api/openapi.yaml` is needed for clients, a golden test regenerates it and fails on a diff; `go test -update` rewrites it.

## DTOs

```go
type createUserRequest struct {
	Login    string `json:"login" required:"true" minLength:"1" maxLength:"64"`
	Password secret `json:"password" required:"true" minLength:"1" maxLength:"1024" format:"password"`
}

type createdUser struct {
	ID    user.UserID `json:"id" format:"uuid"`
	Login string      `json:"login"`
}
```

- The tags describe the field for the spec. They do not validate. The domain `ParseX` / `NewX` validates and stays the one source of the rule; the tag values MUST use the domain constants' numbers.
- Map a DTO to the domain in one function per direction, as the main skill says.
- Decode with `http.MaxBytesReader` and `json.Decoder.DisallowUnknownFields` in one shared `decodeJSON[T]` helper, not per handler.

## Logger middleware

```go
type ctxKey int

const (
	loggerKey ctxKey = iota
	principalKey
)

type statusRecorder struct {
	http.ResponseWriter
	status int
}

func (r *statusRecorder) WriteHeader(code int) {
	r.status = code
	r.ResponseWriter.WriteHeader(code)
}

// Unwrap lets http.ResponseController reach Flush and deadlines.
func (r *statusRecorder) Unwrap() http.ResponseWriter { return r.ResponseWriter }

func logRequests(log *slog.Logger, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		id := r.Header.Get("X-Request-ID")
		if id == "" {
			id = rand.Text()
		}
		w.Header().Set("X-Request-ID", id)
		reqLog := log.With(slog.String("request_id", id))
		rec := &statusRecorder{ResponseWriter: w, status: http.StatusOK}

		next.ServeHTTP(rec, r.WithContext(context.WithValue(r.Context(), loggerKey, reqLog)))

		level := slog.LevelInfo
		if rec.status >= http.StatusInternalServerError {
			level = slog.LevelError
		}
		reqLog.LogAttrs(r.Context(), level, "http request",
			slog.String("method", r.Method),
			slog.String("path", r.URL.Path),
			slog.Int("status", rec.status),
			slog.Duration("duration", time.Since(start)),
		)
	})
}

func loggerFrom(ctx context.Context) *slog.Logger {
	if l, ok := ctx.Value(loggerKey).(*slog.Logger); ok {
		return l
	}
	return slog.Default()
}
```

- The logger MUST be outermost, so that it logs 401, 404, and 413 too.
- A handler MUST log through `loggerFrom(ctx)`, so every line carries `request_id`.
- The middleware MUST NOT log headers or bodies. They carry tokens and personal data.
- `rand` is `crypto/rand`; `rand.Text` needs Go 1.24.

## Auth middleware

```go
type TokenVerifier interface {
	Verify(ctx context.Context, token BearerToken) (Principal, error)
}

func requireAuth(tokens TokenVerifier, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		raw, ok := strings.CutPrefix(r.Header.Get("Authorization"), "Bearer ")
		if !ok || raw == "" {
			writeProblem(w, http.StatusUnauthorized, "The bearer token is missing or wrong.")
			return
		}
		p, err := tokens.Verify(r.Context(), BearerToken(raw))
		if err != nil {
			loggerFrom(r.Context()).InfoContext(r.Context(), "auth refused", "err", err)
			writeProblem(w, http.StatusUnauthorized, "The bearer token is missing or wrong.")
			return
		}
		next.ServeHTTP(w, r.WithContext(context.WithValue(r.Context(), principalKey, p)))
	})
}

// principalFrom panics on a public route: only requireAuth sets the value.
func principalFrom(ctx context.Context) Principal {
	return ctx.Value(principalKey).(Principal)
}
```

- `BearerToken` is a secret type: it prints `redacted`.
- A 401 body MUST NOT say why the token failed. Log the reason through `loggerFrom` instead, never the token.
- Scopes, when needed, are one more row field (`scopes []string`) that the reader passes to both `requireAuth` and `op.AddSecurity(bearerScheme, scopes...)`.
