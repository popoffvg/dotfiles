# Script Manifest

Reusable scripts managed by Claude. Always check here before writing a new script.

| Filename | Description |
| md-comment-probe.py | Drive `md-comment-lsp` over stdio the way Zed does and print what an editor would see: capabilities, the prepareRename range, the rename reply, inlay hints and the code action list, plus whether the store was written. Splits "the server is broken" from "the editor never started it". Args: `[<markdown-file>] [--binary <path>] [--line N]`; with no file it builds a throwaway workspace. Exit 1 when hints or actions come back empty. |
| md-comment-find-anchor.py | Locate an md-comment anchor: print every line of a file whose hash matches, so a comment that points at the wrong line can be traced back to the text it was written on. Args: `<file> <hash>...`, or `--store <.tmp/md-comment.json> [<root>]` to check every stored comment at once. |
| verify-dive-artifacts.sh | Structural check for `/dive docs` research artifacts: markdown tables broken by a mid-table blank line, DP-N/EC-N/RR-N numbering gaps and duplicates (counts definitions only, not cross-doc references), code links pointing at a missing file or past EOF, missing mandatory sections, unresolvable bare repo-root link prefixes. Exit 1 on any problem; an empty file set is an error, not a pass. Args: `<research-dir> [<file>...]`. |
| grammar-check.sh | Fix English grammar of a file or stdin with `claude -p --model haiku --safe-mode`; append one deduped row per fix topic (`date⇥topic⇥explanation⇥context`) to `$GRAMMAR_LOG` (default `~/ctx/grammar/topics.tsv`). Backs the Raycast "Check Grammar" command. Args: `[--quiet] <file>|-` or `--topics [N]`. |
| repos-survey.sh | Read-only survey of every git repo under a root: branch, dirty-file count, upstream, ahead/behind, HEAD. Args: `<root-dir> [out.tsv]`. Run before any bulk update. |
| conflict-sides.sh | Split a file containing diff3 conflict markers into its three whole-file sides. Args: `<file> <out-dir>` → writes `<basename>.ours`, `.base`, `.theirs` and prints their paths. Use to diff the sides before resolving. |
| repos-update.sh | Fetch + **fast-forward-only** pull every clean repo under a root. Skips dirty trees, missing upstreams, and repos with local commits ahead; never merges or rebases. Forces HTTPS-over-SSH so gh's token authenticates. Args: `<root-dir> [out.tsv]` → per-repo status (UPDATED/UP_TO_DATE/SKIP_DIRTY/…) + new-commit counts. Needs sandbox off (SSH is intercepted). |
| blog-discovery-probe.py | Probe an openclaw `scrapers.json`: fetch every enabled source's feed/index and report entries published in the last N hours plus each source's stored watermark. Read-only — never ingests or posts. Tells a quiet-upstream day apart from broken discovery. Args: `[scrapers.json] [watermarks.json] [--hours=N]`. |
| blog-merge-source-lists.py | Merge one openclaw `scrapers.json` source list into another (the one the pipeline actually reads), converting legacy `source`/`rss` entries to the current `id`/`discovery.url` schema and repairing legacy entries already in the target. Dedups on discovery URL, backs the target up, dry-run by default. Args: `<from.json> <into.json> [--apply]`. |
| blog-rewind-watermarks.py | Rewind the dated (rss) discovery cursors in an openclaw blogs `watermarks.json` so the next run rediscovers articles published in the last N hours. Moves cursors backwards only; never touches undated seen-set sources (clearing those floods the digest with a whole index page). Backs up, dry-run by default. Args: `<watermarks.json> [--hours=N] [--apply]`. |
| collect-range-commits.sh | Per-repo commit logs for the exact `old..new` ranges recorded by repos-update.sh — the input for incremental "what arrived since last audit" analysis. Args: `<root-dir> <update.tsv> <out-dir>`. |
| conformance-diff.sh | Diff two block-conformance-scan.sh TSVs: per-column totals before→after with deltas, plus per-block changed cells and NEW BLOCK lines. Args: `<before.tsv> <after.tsv>`. |
| block-conformance-scan.sh | Inventory structural conformance of Platforma blocks under a root dir (facade, block.meta, model API version V1/V3, turbo/pnpm/changeset config, root scripts, eslint, tests, CI, hygiene files). Emits one TSV row per block. Args: `<blocks-root> [out.tsv]`. |
| collect-fix-commits.sh | Sweep every git repo under a root dir for bug-fix-looking commits since a date (keyword grep over subject+body). Writes `<out-dir>/<repo>.log` per repo and prints per-repo counts. Args: `<root-dir> <since-date> [out-dir]`. Used for cross-repo bug retrospectives. |
|---|---|
| doctor-transcript-scan.sh | Aggregate /doctor signals from the N most-recent Claude Code transcripts (default 50): MCP tool calls, skill dispatches, slash commands, per-hook timings + timeouts, and tool denials by kind. Arg: [N] |
| doctor-transcript-scan.py | Same aggregation as doctor-transcript-scan.sh, plus it resolves each denied call back through its tool_use_id to the real tool name and Bash command prefix, and emits one JSON report. **Overlaps doctor-transcript-scan.sh — keep one.** Arg: [N] |
| doctor-skill-listing-cost.py | Estimate the always-resident context cost of the skill listing: walks ~/.claude/skills, <project>/.claude/skills, and installed plugin skill dirs, reads only name+description frontmatter, prints per-skill and per-root est. tokens (chars/4) as JSON. Compare the total against ~1% of the context window. Arg: [project_dir] |
| doctor-user-skill-usage.py | Join ~/.claude/skills against skillUsage in ~/.claude.json: per skill the lifetime usage count (checks both qualified and bare keys), lastUsedAt, metadata.origin, and est. listing tokens; sorted least-used first with a zero-use subtotal. No args. |
| gen-test-fastq.sh | Generate synthetic paired-end <SAMPLE>_1/_2.sub.fastq.gz for import/sample-matcher tests |
| html-to-pdf.sh | Render a local HTML file to PDF with headless Chrome (finds Chrome/Chromium/Brave/Edge). Honors the page's `@media print` + `@page size`, so a slide deck needs a print block revealing every slide. Args: `<input.html> [output.pdf]`. Needs the sandbox off — Chrome writes crashpad/socket files under ~/Library. |
| embed-image-data-uri.sh | Replace a literal marker in a text file with a base64 `data:` URI for an image — for self-contained HTML (published Artifacts, where a strict CSP blocks every external host). Args: `<target-file> <marker> <image-file>`. Idempotent: marker gone → no-op. |
| atuin-to-zsh-history.sh | Convert atuin history export to zsh extended_history format for suv import |
| pl-db-grep-kv.sh | Search RocksDB SST/WAL files for a string pattern in KV metadata |
| lsp-references-smoke.py | Drive tengo-lsp over stdio and issue a textDocument/references request for end-to-end testing |
| lsp-tengo-probe.py | Drive tengo-lsp over stdio and dump what an editor would show for one file: server capabilities, publishDiagnostics, documentSymbol, plus hover + definition at a position. Waits for the initialize RESULT before sending anything else (the server answers -32002 "Server not initialized" to earlier requests). Args: `<binary> <root_dir> <file> [<line0> <col0>]`. |
| cursor-agent-hang-capture.sh | Capture lsof+sample of a hung interactive cursor-agent (agent CLI) to find what startup is blocked on |
| strip-work-skill-prefix.sh | Strip the "work-" prefix from wm skill-name references in given files (Perl word-boundary, idempotent; avoids work-verify-gate/work-abandon/work-next-prompt) |
| openclaw-vault-rekey.sh | Re-key openclaw-infra ansible-vault when old password lost: reconstruct vault.yml from server's rendered telepi config.env over SSH, encrypt with new random password, update Keychain, print new password for GitHub secret. Arg: REPO_DIR (default PWD) |
| regroup-work-skills.sh | Regroup skills under category prefixes: renames global-store dir + recreates repo symlink (or moves real dir), fixes SKILL.md name frontmatter. Args: <repo-skills-dir> <old:new>... (new=__DELETE__ to drop) |
| rewrite-skill-refs.sh | Rewrite skill references in delimited forms only (`old`→`new`, skills/old/→skills/new/, @old→@new) so prose words are never touched. Args: <old:new>... -- <file>... |
| flow-reveal.mjs | Resolve the real source behind a workflow-pseudocode binding and open it in Zed. `reveal <file> <row> [--print]` opens the source for a notable-if ULID (via sibling *.bindings.json) or a .d.ts `@source` tag; `check <dir>` lints that every ULID/@source resolves to an existing path:line. Node, no deps. |
| flow-ulid.mjs | Print N ULIDs (Crockford base32, 26 chars) for tagging notable-if branches in workflow pseudocode. Args: [count] (default 1). Node, no deps. |
| rename-token.sh | Literal, case-explicit token replacement across files. Args: --pair OLD:NEW [--pair ...] FILE... — distinct tokens never collide (literal, not regex); idempotent; reports residual hits. |
| run-pl-backend-sso.sh | Run Platforma backend (pl) with SSO/OIDC auth against the Logto PoC tenant. Args: [--pl-dir DIR] [--root DIR] [--go-run] [--stub] [-- extra-pl-args]. FS primary storage (no minio); Logto values overridable via PL_SSO_* env. |
| tengo-lsp-install-local.sh | Install locally-built tengo-lsp release over VS Code bundled binary + ~/.local/bin (+ /usr/local/bin if writable); ad-hoc codesigns on arm64. Arg: [path-to-binary]. |
| rehome-spec-skills.sh | One-time wm migration: de-symlink plan-* skills from the global store into the repo as real dirs renamed spec-*, then rename plan→spec inside (frontmatter, cross-refs, spec.md, .notes, prose nouns; keeps planning/planner). Arg: [REPO_ROOT]. Overlaps regroup-work-skills.sh + rewrite-skill-refs.sh — reuse those for future renames. |
| rename-plan-refs.sh | Safe identifier-level plan→spec rename in given files (plan-* skill names, plan.md/plan-verify.md, /work:plan-revise, claude-plan, _notes→.notes); no blanket prose rebrand. Idempotent. Args: <file>... |
| graphify_repo_ast_docs.py | Per-repo graphify extraction: AST(code)+semantic(docs only) via claude-cli; writes <repo>/graphify-out/graph.json |
| read-claude-local-subrepos.sh | SessionStart hook: find every git repo (incl. worktrees) under session cwd and emit each repo's CLAUDE.local.md to stdout as context. Prunes node_modules/.venv/vendor/target/dist/build/.cache. Reads cwd from stdin JSON, arg, or $PWD. |
| pty-capture-tui.py | Drive a TUI binary in a pty, snapshot the screen (built-in ANSI model) after each scripted keystroke. Headless, no controlling tty needed. |
| zellij-capture-tui.py | Drive a TUI in a zellij session, dump-screen per step. Note: headless dump-screen returns empty; prefer pty-capture-tui.py. |
| pl-mcp.sh | Call a Platforma desktop MCP tool: pl-mcp.sh <tool> [json-args], PL_MCP_URL env |
| prx-diff-line-check.py | Validate a prx comments file against a unified diff: each `- path:line — body` reported OK / NOT_IN_DIFF (with nearby commentable lines) / FILE_NOT_IN_DIFF / GENERAL. Args: `<diff-file> <comments-file>`. Run before `/prx post` so no inline comment gets rejected. |
| zk-classify.py | Zettelkasten migration Phase 0: classify a vault's .md files into target layers (00-inbox/10-sources/20-notes/30-maps/40-journal/_attic) by pure heuristics. Dry-run — writes reviewable migration_plan.csv, moves nothing. Args: <vault-dir> [out.csv] |
| zk-migrate.py | Zettelkasten migration P1: move files per migration_plan.csv + normalize frontmatter (id/type/status), collision-safe (dedup identical, hash-suffix differing), undo-logged to .ledger/moves.jsonl. Dry-run default; --apply. Reverse with --undo-from. |
| zk-link-backfill.py | Zettelkasten P4: insert [[wikilinks]] from a title+alias index (0 tokens). Conservative: exact-phrase, skips code/headings/existing links, stoplist + domain/attrib exclusions. Dry-run default; --apply. |
| zk-dedup-sources.py | Dedup 10-sources literature notes that are the SAME article: group by source url, cluster within by identical-body OR core-title (strips ` - author`/`(domain)`/hash); distinct articles sharing a url are reported, never merged. Folds dropped names into survivor aliases. Dry-run default; --apply. |
| zk-rename-kebab.py | Align note filenames to their kebab `id` (filename==id). Folds old filename+title into aliases so [[links]] resolve. Ordering-safe two-phase rename (temp then final — never clobbers a queued file). Collision-suffixes duplicate ids. Dry-run default; --apply. |
| zk-lint-links.py | Find/remove stale [[wikilinks]] the way Obsidian resolves (basename+id+aliases — alias-aware, unlike a filename-only check). Removal unwraps to prose ([[X\|Y]]->Y, [[X]]->X); skips code fences. Dry-run default; --apply. |
| zcore-tags.mjs | Extract + tally tags across an Obsidian vault (frontmatter + inline). --json for downstream tooling. |
| zcore-backfill-topic.mjs | Add curated `topic` frontmatter to Z-Core notes derived from existing tags. Dry-run by default; --apply writes. |
| skill-trace-report.py | Report skill invocations from Claude Code transcripts (~/.claude/projects/**/*.jsonl): Skill tool calls + slash commands. --days N, --project SUB, --list, --jsonl. Read-only. |
| openclaw-verify-fetch.sh | Verify the deployed openclaw blogs extension fetches URLs: runs Fetcher.fetchCached over ssh with the live telepi service env, prints title/cached/chars/body-excerpt per URL. Args: <url>... |
| openclaw-session-toolstats.sh | Tool-call statistics for pi/piscord agent sessions on the openclaw server (parses session .jsonl over ssh with jq). Modes: default = per-tool call counts, `--bash-verbs` = histogram of the first word of each bash command, `--bash-commands` = raw command strings. Args: `[--host H] [--root DIR] [--since YYYY-MM-DD] [--top N]` |
| note-new.sh | Create one personal note file at `<repo-root>/.note/personals/YYYY-MM-DD-<slug>.md` with kind/created/repo/branch frontmatter. Body from stdin; never clobbers (suffixes -2, -3). Args: `<todo|thought|reminder|question> <title>`. Used by the `note` skill. |

Env: RESEARCH_DIR, TASK_CONTEXT, MODEL, FORCE. Args: `slug=entry point description`... |

Prints `id  title  (file)`; `--count` / `--files` for scripts. Exit 0 = none open, 1 = at least one open, 2 = usage/missing dir. Args: `[thoughts-dir] [--count\|--files]` (dir defaults to `.notes/thoughts`, `_notes/thoughts`, `thoughts`). |

| lumen-pane.sh | Open `lumen diff` in its own full-window herdr tab and collect the annotations it writes on exit (`i` annotate, `s`+Enter exit-and-send). A TUI cannot run in a Claude Code Bash call — no tty, dies with `EAGAIN` / os error 35. The tab label is the identity: re-running focuses the open tab instead of a second copy. Runs under `exec` with stdout redirected to `$TMPDIR/lumen-annotations-<label>.md`, so quitting closes the tab and keeps the output. `--wait` blocks until the viewer exits, then prints the annotations with the terminal escapes stripped. Backs `/lumen` and `/lumen-last`. Args: `[--wait] <tab-label> [lumen-diff-args...]`. |
| open-file.sh | **Every script or skill that hands the operator a file to edit calls this — never pick an editor inline.** Routes by host: Zed terminal (`$ZED_TERM` or `$TERM_PROGRAM=zed`) → `zed --existing`; herdr pane (`$HERDR_PANE_ID`) → `$EDITOR` (default `hx`) in a zoomed split under the calling pane; neither → prints the path and opens nothing, because a TUI editor in a Claude Code Bash call has no tty and dies with EAGAIN (os error 35). Zed wins when both apply. `--wait` blocks until the file is closed (`zed --wait`, or polling until the pane dies). Args: `[--wait] <file>...`. |
| render-j2-yaml-check.py | Parse a Jinja2-templated YAML file as YAML by substituting every `{{ var }}` with a placeholder, and optionally assert dotted key paths exist. Catches indentation/key-shape errors in an ansible template without a venv or the real inventory. Args: `<file.j2> [--has a.b.c]...` |
| ansible-vault-set-key.sh | Add or replace one key in a **JSON** ansible-vault file without opening `$EDITOR`. Pipes decrypt → jq → encrypt so the cleartext never touches disk; reads the value from `$VAULT_VALUE`, not argv (which `ps` exposes); passes `--encrypt-vault-id` (override via `$VAULT_ID`) because `encrypt` refuses when a config offers more than one id; verifies the re-encrypted copy decrypts and carries the key before replacing the original. Args: `<vault-file> <password-file> <key-name>`. |
| adr-session-end-hook.sh | `SessionEnd` hook that reminds the operator to record an ADR when a session discussed an architecture decision and wrote none. Reads the hook JSON on stdin, greps `transcript_path` for a narrow decision regex, and writes to **stderr** (SessionEnd stdout reaches nobody). **Off by default**: it stays silent unless the repo opted in with `.claude/adr-reminder.on` (or one run with `ADR_REMINDER=on`); `ADR_REMINDER=off` overrides the marker. Also silent when `docs/adr/` already has uncommitted changes. Prints the next ADR number across `docs/adr/` and `docs/!archived/adr/`. Copied into a target repo by the `repo-settings` skill. |
| yazi-opener-probe.sh | Verify a yazi `[open]` rule actually fires for a file type: creates a throwaway file, runs yazi in a `script(1)` pty, sends Enter then `q`, and reports whether the configured opener wrote its probe file. Args: `<config-home> <test-filename> <probe-file>` |
