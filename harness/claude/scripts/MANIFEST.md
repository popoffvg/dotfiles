| skill-archive-and-prune.sh | Make a loose skill's deletion reversible, then delete it. Commits the skill first (moving it into the repo if it lived outside, committing in place if it was symlinked in but never `git add`ed — a skill in the repo tree is NOT necessarily in git), then removes it in a SECOND commit and deletes the now-dangling `~/.claude/skills` symlink.
